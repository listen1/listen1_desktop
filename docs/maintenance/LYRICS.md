# 本地导入与歌词管理验证

2026-10-07，在 Windows x64 工作区使用 Node 24.21.0、npm 12.0.2、Electron 44.4.3 及已安装锁定依赖验证。保持 AngularJS、两套布局、原歌曲 ID 和播放来源；没有升级依赖、提交、推送、更新子模块指针或发布。开始时两个仓库均无既有未提交差异。

## 实现

新本地歌曲使用不含扩展名的文件名，标签中的歌手和专辑预填且可清空。重复导入跳过旧 ID，保留原记录与顺序。本地歌曲可编辑歌名、歌手和专辑；修改按 ID 更新本地库、自建歌单副本、持久队列及播放核心，保留音频实例、位置和播放状态。

两套布局的当前播放页、搜索歌曲、歌单和队列使用共享歌曲操作指令，打开同一个歌词管理对话框。2026-10-08 起，精简弹窗保留本地导入、恢复及可展开的时间对齐；关键词、平台和候选迁移到独立搜索页面。目标歌曲在打开时固定，默认搜索现有七个可见平台，输入防抖 500ms、回车立即搜索；平台筛选读取缓存，分页只补齐缺少的页，各平台失败独立重试。只请求被选择候选的原歌词，候选明确应用后留在页面。本地文件先预览后应用，无有效同步正文不能保存。

新增受信任主窗口 IPC `importLocalLyric()`，单文件 `.lrc`，严格 UTF-8（允许 BOM），读前与读取中均限制 1 MiB。原音频、标签和同名 sidecar 容错流程保留。共享解析支持空行、元数据、LF/CRLF、无小数或 1～3 位小数及多时间戳；手动文件的错误正文报告行号。

替换保存到 `lyric-override:${trackId}`，当前格式为 `{ lyric, tlyric, offsetMs }`，原歌词可仅保存 `{ offsetMs }`；旧版本 `{ lyric, tlyric }` 默认偏移 0，不批量迁移。自动纳入现有 localStorage JSON/Gist 遍历。同名不同 ID 互不覆盖，同 ID 跨歌单共享。没有有效独立译文时保存空译文，并立即清除主界面和悬浮窗旧译文。恢复先获取原 provider，成功后删除替换键，失败保留旧内容与偏移并可重试。存储失败保留旧替换且不发布成功事件。

时间对齐以整数毫秒保存，每次提前 −300 或延后 +300，范围 ±60000，提供归零。调整独立于候选的明确应用，保存成功后立即发布偏移事件并请求当前帧，暂停时生效且不重新获取歌词。原文与译文统一按“播放时间 ≥ 时间戳＋偏移”显示，主界面与悬浮窗共用结果，不改变音频位置。应用歌词一次写入内容及零偏移；预览、取消和失败均不归零。无同步正文时禁用提前/延后，已有非零偏移仍可归零。

搜索、预览和播放歌词分别检查请求代次、目标 ID 及作用域生命周期，包含 Angular 排队回调的再次检查。保存后强制刷新当前歌曲，暂停时请求新播放帧重算高亮；主进程缓存最新原文/译文对，悬浮窗加载完成后补发，防止暂停后新开窗口空白。
