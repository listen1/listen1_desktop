# RMS 音量均衡：实现与验证

日期：2026-10-06。范围：Windows x64、源码启动的 Electron 44.4.3 桌面版。主仓库负责只读资产准备与 IPC；共享子模块负责 RMS、播放适配、状态、界面及翻译。参见 [ADR](../adr/0001-rms-audio-playback.md) 和 [术语表](../../app/listen1_chrome_extension/GLOSSARY.md)。本轮未提交、推送、发布或改变父仓库的子模块提交指针。

## 实现行为

- 默认关闭、首次模式为标准；新增 `loudness-settings` 只保存开关和模式，不迁移已有键。重启恢复设置，尚无播放时显示等待播放；主题重建控制器从播放核心获取真实状态。
- 只准备当前曲目完整最终资产。100 ms 分块一次扫描能量和样本峰值，按源音频 −60 dBFS 门限排除近静音块，以有效样本数加权形成整曲 RMS。各段共用一个增益，不追随主音量或单独放大静音／弱段。
- 两模式分别以 −20 dBFS 为初始参考，目标在当前播放核心运行期间只下调；正增益最多 24 dB，样本峰值保留 6 dB 余量。标准最多使用 1 dB、声道联动限峰，5 ms 提前包络、100 ms 恢复；复测误差超过 0.5 dB 时下调目标并采用固定增益。高动态只施加固定增益。
- 分析与播放使用相同完整资产。均衡增益位于主音量之前；静音／音量零同时作用于当前输出和正在释放的短淡出输出。开始、暂停、跳转、结束使用最多 15 ms 淡入淡出，曲内主体不做逐段补偿。
- 开启、切换模式或更换当前源会保留进度和播放意图，暂停后准备。分析中暂停，完成后保持暂停。切歌、清空、换源、设置变化使旧任务失效，旧结果不能播放或下调目标；队列追加不预分析或打断当前音频。
- 每次读取超时 30 秒，临时失败重试一次，仍失败保持暂停，弹层提供重试及关闭功能。明确不可解码、无有效电平、不支持声道或超出允许音源范围显示未均衡原因，使用原播放链。原链也无法播放的损坏文件不会变成可播放文件。

目标下降影响当前准备和后续播放，无法修改过去已播放的片段；缓存重播也按新目标生成增益。页面重新加载重建目标／测量摘要，仅切换主题不会重建播放核心。

## 资产和资源边界

新增 `prepareAudioSource`、`readAudioSource`、`cancelAudioPreparation`、`releaseAudioSource` 四个 preload 接口，沿用主窗口、主 frame、准确本地页面校验，不暴露原始 IPC。网络使用当前主窗口 session，保留现有请求头、代理及 Cookie 边界；按平台验证音源和每次重定向。实测 Bilibili CDN 使用 HTTPS `*.mcdn.bilivideo.cn:8082`，只对此范围增加端口例外。没有新增通用 URL／任意文件读取入口。

本地沿用绝对路径 `lmtrack_` ID 和允许扩展名，只读访问，读取前后检查文件身份属性，完整字节以 SHA-256 标识。压缩缓存共 128 MiB，单资产最多 128 MiB；远程 URL 缓存五分钟，本地每次核查文件属性。最多两个准备请求、四个分块租约；导航释放请求／租约，退出清空缓存。

共享层保存当前解码缓冲和最多 128 个指纹测量摘要；切歌释放解码引用，相同资产重播可再次解码而不扫描。解码后检查 PCM 最多 256 MiB、最多双声道。以上是资产限制，**不是进程内存峰值上限**：原生解码先于检查，标准处理、IPC 还会产生临时缓冲。慢网络或长曲目可能超时／达到资源限制，用户可重试或关闭功能。所有生产缓存只在内存中；未增加处理依赖、改变 vendor 或锁文件。

## 客观测量

环境为隔离 Node 24.21.0、npm 12.0.2、Electron 44.4.3、FFmpeg 9.0.2；位置和下载校验见 [工具清单](../../dist/maintenance/tools/loudness-validation-tools.json)。测试 profile、音频、报告和截图只存于忽略的 `dist/maintenance`，未读取真实用户 profile、改写用户音频或迁移用户数据。

真实桌面准备接口完成读取／解码，生产 BufferAudio 类通过 OfflineAudioContext 导出 WAV。按源有效块独立测量输出 RMS，FFmpeg `astats` 复核电平，`ebur128=peak=true` 检查整曲真峰值；原始与处理资产输入 SHA 对照一致。没有仅凭播放状态或音量百分比判断均衡。

### 共同目标的阶段

本地先遇到极低电平 quiet，24 dB 增益限制使目标降到 −22.733215；高峰均比素材使标准／高动态分别降至 −32.573078／−33.573078。quiet 重播采用最终目标，无重复扫描。

在线为独立运行：酷狗／咪咕阶段目标为 −22.542848／−23.542848，Bilibili 后续阶段及单源复查为 −22.824514／−23.824514；Bilibili 实测 −22.824904／−23.824514 dBFS。历史导出对应当时目标阶段，**不能将全部历史 WAV 当作同一最终目标**。已验证目标只下调、重播应用新目标，没有追溯重渲染过去所有歌曲。

### 2026-10-11 图标与弹窗收起修复

公共 SVG 的 `fill: none` 覆盖了图标的填充属性；现以均衡按钮作用域内的 `fill: currentColor; stroke: none` 恢复实心三滑杆。经典布局默认沿用音量图标色，现代布局沿用同栏正文图标色（浅色黑、深色浅）；启用仍使用主题强调色，图标保持 18 px。

鼠标在弹窗与底部控制区内往返保持展开，离开整组 200 毫秒后关闭并在现代布局恢复时长。现代整组包含时长／进度／音量区及弹窗，经典整组包含均衡按钮、相邻音量区及弹窗；跨越间隙后返回取消计时。显式展开及键盘焦点状态替代无条件 `:focus-within`，点击留下的焦点不再阻止收起。原生模式选择框打开时暂缓关闭；Tab 在内部导航不关闭，离组关闭，Esc 关闭并回到按钮。焦点判断避开 Angular blur 更新时 `activeElement` 短暂成为 body 的阶段，主题销毁清理全部监听与计时器。

## A/B 试听与复现

[试听材料](../../dist/maintenance/loudness/listening.html) 包含本地强瞬态及三个成功在线样本的原始、标准、高动态、标准电平匹配版本，初始播放音量 10%。比较音质时使用电平匹配版本；无需限峰时两种模式可以相同。完整软件链路导出在同目录，`active` WAV 删除了测量排除块，仅供测量。

人工试听尚待用户确认，未把生成材料或 RMS 一致写作人耳验收通过。RMS 是本次采用的平均电平定义，不保证不同频谱作品感知响度完全一致。6 dB 是样本峰值余量，真峰值可能略高；本轮最高 −5.7 dBTP，不保证未知素材也有 6 dB 真峰值余量。

在固定工具链及已安装依赖下，从根目录执行：

```powershell
npm test
npm run lint --prefix app/listen1_chrome_extension
npm run vendor:check --prefix app/listen1_chrome_extension
npm run test:electron
node tests/loudness-electron.cjs
# 可选：实际游客在线样本，受网络／平台状态影响
$env:LISTEN1_LOUDNESS_ONLINE = '1'
node tests/loudness-electron.cjs
node scripts/loudness-listening.cjs
```

可用 `LISTEN1_FFMPEG` 指定 FFmpeg；默认读取隔离工具目录。`LISTEN1_LOUDNESS_SOURCES` 可指定逗号分隔的平台，已有报告时保留其他平台证据；`LISTEN1_LOUDNESS_SKIP_LOCAL=1` 仅在已有本地证据时复用，不能算重新测量。
