# 界面、封面与歌曲详情维护记录

2026-10-09，Windows x64 源码验证。使用既有 Node 24.21.0、npm 12.0.2、Electron 44.4.3、Playwright 1.63.0；未升级依赖或重写锁文件。开始时主仓库和独立播放器子模块均干净，本轮交付未提交、推送、修改子模块提交指针、打包或发布。

## 实现

- 四主题保留原有颜色变量、经典紧凑结构和现代卡片/封面表现。新增公共 `visual-polish.css` 在主题 CSS 之后加载，统一间距、横向操作组、原生歌名提示及焦点/悬停状态。详情标签的颜色由主题正文/次要文字混合，现代选中行操作图标使用主题强调色。
- 歌词与详情复用 Feather `align-right`、`info`，其几何与提供的 SVG 一致；显式设置 currentColor、fill:none、尺寸和经典 1.5/现代 2 的描边。歌词与本地编辑相邻，清除通用 span 徽标样式。业务条件继续控制删除/来源按钮，不因聚焦误显示。
- 现代收起侧栏保持 60px，图标和封面不缩小，隐藏文字占位并限制横向滚动。自建/收藏歌单使用封面缩略图，失败回退现有默认封面，导航和拖放入口保留。现代设置补齐葡萄牙语入口。
- 本地编辑提供 PNG/JPEG/WebP 选择、真实解码、预览和确认保存；限 10 MiB、边长 8192 及 4000 万像素。副本保存在当前 userData 的 `covers/<UUID>/`，记录保存 UUID/原文件名；取消或失败保留旧数据。确认先事务式更新本地库、相关歌单和持久队列，再更新核心显示字段，保持 ID、Howler、播放位置及状态。
- WebP 使用无 preload/Node、启用 sandbox 的临时隐藏 Chromium 窗口，独立非持久 session、禁网络/文件导航，完成、关闭或超时销毁。PNG/JPEG 使用 nativeImage；其 buffer 支持范围见 [Electron 文档](https://www.electronjs.org/docs/latest/api/native-image#nativeimagecreatefrombufferbuffer-options)。未引入图像依赖。
- 两布局的列表、搜索结果和队列提供统一歌曲详情按钮，播放栏保留歌词操作。详情按约定顺序显示十项，网络追加歌词平台；缺失留空，路径和长文本可换行、选中复制。封面文件名仅来自用户实际选择，歌词文件名仅来自明确文件来源。
- 本地详情通过实际解析和 stat 补充旧记录，保留编辑后的标题/歌手/专辑。网络信息须手动读取，最多解析读取 8 MiB、总预算 15 秒；使用实际已加载/换源音源，其他目标只解析地址，不操作队列。Range 可跳过 MP4 音频数据读取尾部，非 Range 也有界读取。资源身份变化清空本次结果，超时或读取不足仅保留确认字段。
- 信息缓存仅在本次运行有效，最多 128 项、TTL 五分钟，按歌曲及实际音源绑定。关闭、目标/主题/音源变化取消请求；异步结果在进入和执行 Angular 更新时均核对目标/代次。格式来自解析 codec/container，音质只展示确认的无损/有损、码率、位深、采样率。
- 歌词替换兼容可选 `provenance`，保留原文/译文/偏移。文件导入保存实际 basename，候选替换保存实际平台，恢复成功才切回原来源；旧来源未知时留空，音频换源不覆盖歌词平台。

JSON/Gist 只保存封面引用，跨设备恢复须同时迁移 userData 的 `covers` 目录。已提交副本保留供旧备份使用；本轮没有实现自动垃圾回收或测试跨设备迁移。

## 真实线上抽查与边界

[游客线上报告](../../dist/maintenance/visual-1791519927444/report.json)中，以“夜曲”抽查网易、QQ、酷我公共歌曲元数据，不播放远程音频，不保存 Cookie、令牌或播放 URL。网易样本成功解析 MPEG 1 Layer 3、128 kbps、44.1 kHz、有损、约 234 秒，可靠资源大小为 3,744,690 B；QQ 返回 `SERVICE_ERROR`，酷我地址解析返回 `ALL_SOURCES_FAILED`。脚本正常退出不能解释为全部平台通过。线上抽查后还修复了 WebP 解码并完成最终离线回归。
